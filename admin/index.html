Operasi Database

1. Ekspor Cadangan (Backup JSON)

Unduh seluruh data (fungsionaris, proker, berita, notulensi, aspirasi) dalam format file JSON.

2. Pulihkan Cadangan (Restore)

Pilih file JSON cadangan untuk memulihkan seluruh basis data.

3. Reset ke Data Bawaan Pabrik

Kembalikan seluruh basis data ke kondisi awal sistem (1 Superadmin, Pengurus Bawaan, dan kuota 30 fungsionaris).
