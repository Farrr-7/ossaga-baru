# OSSAGA - Portal Resmi OSIS SMAN 1 SAGARA

Website resmi Organisasi Siswa Intra Sekolah (OSSAGA) SMA Negeri 1 SAGARA periode 2026/2027.
Mengusung konsep desain **Modern Creative • Futuristic • Dark Navy Theme** dengan arsitektur web interaktif mandiri.

## 🌟 Fitur Utama
- **Portal Terbuka & Fungsionaris Khusus**: Informasi umum (warta, agenda, galeri, proker) dapat diakses bebas tanpa login, dengan sistem autentikasi fungsionaris (30 kuota NIS) untuk akses portal internal pengurus.
- **10 Seksi Bidang Interaktif**: Floating tooltip & dynamic preview kartu sekbid saat kursor diarahkan ke nomor sekbid (01-10).
- **SAGARA Arcade Zone**:
  - *Mode 1 (2D Action Runner)*: Mini game "Tangkap Aspirasi" dengan efek suara Web Audio API, sistem combo, dan high score.
  - *Mode 2 (Kuis Kepemimpinan)*: 5 soal interaktif seputar kepemimpinan dan kode etik sekolah dengan evaluasi langsung.
- **Lensa Galeri & Lightbox**: Filter foto kategori Kegiatan, LDKS, dan Porseni dengan pop-up preview layar penuh.
- **Kotak Aspirasi Siswa**: Form kirim aspirasi langsung tanpa perlu login.
- **Admin Dashboard BPH**: Manajemen pengurus, warta berita, agenda, proker, dan respon aspirasi.

## 🚀 Cara Deploy ke Vercel
1. Upload folder ini ke repository GitHub Anda (misal `ossaga-web`).
2. Kunjungi [vercel.com](https://vercel.com) dan login dengan akun GitHub.
3. Klik **Add New...** > **Project** lalu pilih repository `ossaga-web`.
4. Klik tombol **Deploy**.
5. Website langsung online dengan domain gratis `.vercel.app`!
